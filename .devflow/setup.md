# devflow Setup Guide

Prerequisites for local development. Install these tools to get full
pre-commit enforcement. Without them, checks run in CI only.

## Core Tools (all projects)

- **trivy** — Secrets + CVE scanning
  ```brew install trivy```
- **semgrep** — Security pattern scanning
  ```brew install semgrep```

## Python Tools

- **ruff** — Python linting + formatting
  ```pip install ruff```
- **black** — Python code formatting
  ```pip install black```
- **bandit** — Python security scanning
  ```pip install bandit```
- **pip-audit** — Python dependency provenance
  ```pip install pip-audit```
- **pip-licenses** — Python licence compliance
  ```pip install pip-licenses```

## Javascript Tools

- **eslint** — JavaScript linting + security
  ```npm install -g eslint```
- **prettier** — JavaScript formatting
  ```npm install -g prettier```
